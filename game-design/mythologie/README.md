# Mythologie

[genealogie-dieux-grecs.html](genealogie-dieux-grecs.html) : l'arbre généalogique interactif des divinités grecques, du Chaos aux enfants des Olympiens (233 fiches). Ouvre le fichier dans un navigateur ; il marche sans internet. Les 12 dieux du jeu ont un point de la couleur de leur planète.

Il sert de référence pour nommer les skills, les super ennemis et les futurs dieux.

- **Sources :** Hésiode, Homère, Apollodore, Hygin, Pausanias, Ovide, comparés aux généalogies de Harold et Jon Newman (préface de Timothy Gantz), du Theoi Project et de Wikipédia.
- **Contradictions :** quand les sources se contredisent, l'arbre garde la version à deux parents, sinon la plus ancienne. Les 35 choix sont expliqués en bas de la page.
