Comment ça marche ?
  1. Change des valeurs. Un réglage changé devient orange, avec sa valeur d'avant en dessous (le bouton ↺ la remet). Tes changements sont gardés dans ce navigateur tant que tu ne les as pas enregistrés.
  2. « ▶ Tester dans le jeu » ouvre le jeu dans un nouvel onglet avec ces valeurs. Pendant ce test, rien n'est sauvegardé : ta progression ne change pas (un bandeau 🧪 le rappelle).
  3. « 💾 Enregistrer » réécrit le fichier reglages.js. Choisis celui qui est à la racine du dossier du jeu (à côté de index.html) et remplace-le. Si ton navigateur ne sait pas enregistrer directement, le fichier est téléchargé : mets-le à la place de l'ancien.
  4. Recharge le jeu (F5) : il utilise les nouvelles valeurs. Puis, dans GitHub Desktop : Commit, puis Push (le site et l'appli prendront les nouvelles valeurs).
  5. Les documents de game-design/ citent les valeurs : relance node game-design/outils/generer-docs.js (prix, skills, la liste des réglages), ou demande à Claude de les mettre à jour.

Les pourcentages s'écrivent ici en % (10 = 10 %). Dans le fichier, ils sont en fraction (0.1). Le petit nom gris sous chaque réglage est son nom dans le code (index.html le lit avec reglage("NOM")). ⚠️ = ce nombre est aussi écrit dans un texte du jeu : si tu le changes, pense à changer ce texte.
